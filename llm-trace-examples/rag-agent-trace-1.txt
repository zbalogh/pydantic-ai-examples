===== VÁLASZ =====

To take an online full backup in ACS 2.4, follow these steps:

1. **Ensure PostgreSQL 15 WAL Archiving is Enabled**: ACS 2.4 supports online full backups only when WAL archiving is enabled.

2. **Use an Approved Backup Process**: Your organization's approved backup process must capture a consistent database snapshot along with the required WALfiles.

3. **Backup the ACS Configuration File**: Copy the active configuration file located at `/etc/acs/acs.yaml` and include it in the same backup manifest.

4. **Verify the Backup Job**: Ensure that the approved backup job reports a completed and recoverable snapshot.

5. **Store Artifacts and Record Details**: Store the backup artifacts (database and configuration file) together under a specific location, and record relevant details such as ACS version, PostgreSQL version, creation time, and database host in a manifest.

By following these steps, you can successfully perform an online full backup of ACS 2.4 while the `acs-server` is running.
